# 📋 음성 합성(TTS) 및 인식(STT) 전처리 성능 비교 보고서

## 1. 개요 (Overview)
* **목적**: 한국어 텍스트 정규화 전처리(특수문자 정리, 띄어쓰기 및 문장 부호 표준화 등) 적용 여부가 음성 합성 품질 및 STT 인식 성능에 미치는 영향 정량 분석
* **사용 모델**: 
  * **TTS**: `edge-tts` (`ko-KR-SunHiNeural`)
  * **STT**: `faster-whisper` (`base` 모델, CPU, int8)
* **평가 지표**: 
  * **음성 인식 점수 (Score)**: 문자 오류율(CER)을 기반으로 산출된 100점 만점 정확도 지표
  * **음절 오류율 (CER, Character Error Rate)**: 낮을수록 우수
  * **SDI 오류 유형**: 치환(Substitution), 삭제(Deletion), 추가(Insertion) 세부 오인식 건수
